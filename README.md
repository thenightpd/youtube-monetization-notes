# 유튜브 수익화 자료 — 유튜브 자동화 챌린지 1기

수강생에게 주기 전에 **직접 확인하고 직접 잰** 자료입니다. 남의 조사 결과를 옮긴 것이 아닙니다.

## 무엇이 들어 있나

| 경로 | 내용 |
|---|---|
| `pages/수익화까지-몇편.html` | 주제 고르기 전에 읽는 자료. 수익화 문 두 갈래, 왜 롱폼이 먼저인지, 우리 네 트랙이 어디에 해당하는지 |
| `pages/시니어사연-실측.html` | 시니어 사연 채널 12곳 실측표와 측정 방법 |

| `data/결과.json`, `data/결과2.json` | 측정 원본 데이터. 채널별 전 영상의 조회수·길이가 그대로 들어 있습니다 |

## 확인한 기준 (2026-09-17)

유튜브 공식 문서에서 직접 확인했습니다.

- 파트너 프로그램 가입: 구독 1,000명 + **시청시간 4,000시간(최근 12개월)** 또는 **쇼츠 조회수 1,000만 회(최근 90일)**
- **2027년 2월 1일부터** 신규 신청자 기준이 8,000시간 / 2,000만 회로 오릅니다. 이미 파트너인 채널은 영향받지 않습니다
- 같은 날부터 기존 파트너도 쇼츠 광고 수익을 받으려면 90일 1,000만 회를 유지해야 합니다. 못 채워도 자격은 유지되고 롱폼 수익은 나옵니다
- 비진정성 콘텐츠 정책(2025-07-15 개칭)은 새 정책이 아니라 기존 규칙을 명확히 한 것입니다. AI 도구 사용은 막지 않으며, 조건은 최종 영상에 사람이 더한 고유한 가치가 있을 것입니다

출처 링크는 `pages/수익화까지-몇편.html` 맨 아래에 있습니다.

## 측정 방법

`yt-dlp`로 채널의 공개 영상 목록(메타데이터)만 받았습니다. 영상은 내려받지 않았고, 요청 사이에 4초씩 쉬었습니다. 채널당 최근 50편까지 보고 조회수의 **중앙값**을 썼습니다. 평균은 대박 한 편에 끌려다녀서 채널의 평소 실력을 못 보여 줍니다.

```
yt-dlp --flat-playlist --playlist-end 50 --print "%(view_count)s %(duration)s" "<채널주소>/videos"
```

## 다시 잴 때

```
python3 -m venv venv
./venv/bin/pip install yt-dlp
./venv/bin/python data/measure.py
```

기준일이 지나면 숫자는 달라집니다. **수강생에게 주기 전에 다시 재세요.** 실제로 3주 사이에 조회수가 5배로 변한 채널이 하나 있었습니다.

## 조심할 것

- 조회수는 누적이라 오래 올라가 있던 영상이 유리합니다. 채널끼리 비교하는 용도이지 절대값이 아닙니다
- 유튜브가 주는 조회수는 반올림된 값입니다
- 표본이 작은 채널이 셋 있습니다(3편·13편·10편). 참고만 하세요
- 끝까지 본 비율 10%는 가정입니다. 실제 값은 자기 채널 분석에서만 보입니다
- 채널 선정은 검색으로 했습니다. 장르 전체를 대표하지 않습니다
